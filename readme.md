# Landing Page Juwenalia AT Tarnów 2026

Projekt stworzony w ramach zajęć z pracy zespołowej. Strona promuje tegoroczne Juwenalia organizowane przez Akademię Tarnowską.

## 🛠 Technologie
* **HTML5** - Struktura dokumentu
* **CSS3** - Stylizacja i layout (Flexbox/Grid)
* **JavaScript** - Interakcje (skrypty w przygotowaniu)
* **Git** - Kontrola wersji (Workflow: GitFlow/Feature Branches)

## 🚀 Instrukcja uruchomienia
1. Sklonuj repozytorium: `git clone [link-do-repo]`
2. Otwórz folder projektu w **Visual Studio Code**.
3. Zainstaluj wtyczkę **Live Server**.
4. Kliknij prawym przyciskiem myszy na `index.html` i wybierz **"Open with Live Server"**.

## 📁 Struktura projektu
* `index.html` - Główny plik strony.
* `style.css` - Arkusz stylów (zmienne, layout, animacje).
* `script.js` - Logika strony (np. odliczanie do wydarzenia).
* `assets/` - Katalog na grafiki i zdjęcia.
